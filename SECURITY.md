# Security policy

Report suspected security vulnerabilities using GitHub's
[private vulnerability reporting](https://github.com/MorphIQ-Labs/morphiq-risk-ml/security/advisories/new).
Include the exact commit, OCaml/compiler/platform versions, a minimal reproducer,
observed impact and any proposed fix. Keep exploit details and sensitive data
out of public issues while the report is assessed.

This is an experimental, volunteer-maintained project. Security fixes target
the current default branch; there are no maintained release branches or promised
response times. Pin integrations to a reviewed commit and track upstream fixes.
The maintainer will assess reports privately and coordinate a fix and disclosure
with the reporter where practical.

Ordinary numerical inaccuracies, API failures and performance bugs belong in
[public issues](https://github.com/MorphIQ-Labs/morphiq-risk-ml/issues), unless
they disclose an exploitable vulnerability or sensitive information. Numerical
certificates bound arithmetic error under documented model assumptions; they
do not establish security, market-data validity or institutional approval.
